# Privacy Policy — Search & Translate Panel

**The extension / userscript has no server and does not collect, store or sell any personal data.**

What stays on your device (browser storage): settings, panel position, translation history (last 50 items), cached site icons, and the optional OCR.space API key you enter yourself.

What is sent to third parties, only when you use the corresponding feature:

| Feature | Data sent | Recipient |
|---|---|---|
| Translation (selected text, clipboard text, page translation) | the text being translated | Google Translate (`translate.googleapis.com`), MyMemory (`api.mymemory.translated.net`) |
| OCR (image → text) | the image | OCR.space (`api.ocr.space`) |
| Site icons for buttons | the host name of the site | Google (`www.google.com/s2/favicons`), DuckDuckGo (`icons.duckduckgo.com`) |

These services have their own privacy policies. Requests are sent without cookies. Nothing is sent until you trigger the feature.

The extension reads the clipboard only when you press the "translate clipboard" hotkey and writes to it only when you press "Copy".
